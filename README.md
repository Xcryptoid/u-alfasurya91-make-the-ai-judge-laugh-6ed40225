One-line joke about office life for the [Make the AI Judge Laugh](https://make.fun/bounty/u-alfasurya91-make-the-ai-judge-laugh-6ed40225) bounty on make.fun.

## The entry

> The printer only jams when the document matters: it is the most honest performance review in this office.

105 characters, 18 words, one line. The joke turns the office printer — the one machine that never lies about a deadline — into the only honest performance review in the building.

## How it works

`main.py` is a stdlib-only copier: it copies the pre-written `entry.txt` into the output directory the grader provides (`MAKEFUN_OUTPUT_DIR`, default `/output`). Nothing is rendered at grade time, so the output is byte-identical on every run.
